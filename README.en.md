# Learning English 🇬🇧

**Languages:** [中文](README.md) | [English](README.en.md)

![Learning English Banner](jjj.png)

A curated collection of high-quality English learning resources focused on core skills: listening, speaking, reading, and writing. Includes grammar, vocabulary, and media resources to help you learn English more effectively.

**Who is this for:**

- English learners at all levels
- Self-learners looking for structured practice
- Educators seeking teaching resources
- Professionals who need English for work, study, or travel
- This project is continuously updated — great resources will be added as they are discovered!
- Official website: [https://en.knowledgefxg.com/](https://en.knowledgefxg.com/)
